# ContentSpark AI 📝✨

An AI-powered multi-platform content creation and SEO planning assistant built with **Streamlit** and **Groq**.

## Features
- **📊 SEO Planner:** Generate meta tags, keywords, and comprehensive blog outlines.
- **🚀 Multi-Platform Repurposing:** Turn one idea into LinkedIn posts, Twitter threads, and social captions instantly.
- **💬 Interactive Editor:** Chat with the AI to refine and customize your drafts.

## Deployment on Streamlit Cloud
1. Push these files to GitHub.
2. Deploy on [Streamlit Community Cloud](https://share.streamlit.io/).
3. Add your Groq API key under app settings **Secrets**:
   ```toml
   GROQ_API_KEY = "gsk_your_actual_groq_api_key_here"
